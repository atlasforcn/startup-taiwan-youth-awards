# 台灣大學創業競賽作品整理系統

這個 repo 是大學/青年創業競賽作品的整理網站。目前收錄教育部青年發展署 U-start 創新創業計畫、U-start 原漾計畫與 Young 飛全球行動計畫近五年官方績優/得獎團隊，並標記哪些作品適合先做成軟體原型。

## 已整理範圍

- 競賽：U-start 創新創業計畫、U-start 原漾計畫、Young 飛全球行動計畫
- 主辦：教育部青年發展署
- 屆次：110、111、112、113、114 年度官方績優/得獎團隊
- 收錄：224 筆作品
- 可軟體實作候選：98 筆
- 已建立原型 repo：8 筆

## 資料判斷規則

- `明確`：官方作品名稱已直接呈現平台、系統、AI、資訊服務、市集、媒合或 App 類型。
- `推測`：作品名稱與類別顯示可軟體化，但仍需要補查簡報、官網或新聞。
- `待查`：公開名單只足以確認得獎資訊，暫不臆造核心產品。

## 已開原型

- `prototype-notex-marketplace`：依 114 年 U-start `NoteX 筆記市集` 做出的筆記交易/學習資源市集。
- `prototype-internship-match`：依 114 年 U-start `實習通` 做出的實習媒合管理平台。
- `prototype-rag-semiconductor-workbench`：依 114 年 U-start `RAGtimAIze 半導體智慧模組串接平台` 做出的 RAG 模組工作台。
- `prototype-shared-fashion-platform`：依使用者補充概念做出的台灣共享時尚/服飾租借平台；獎項來源與屆次待查。
- `prototype-idjalan-cultural-routes`：依 113 年 U-start 原漾 `I Djalan 在路上` 做出的文化路線與體驗預約平台。
- `prototype-boringai-workflow`：依 114 年 U-start `BoringAI` 做出的 AI 工作流平台。
- `prototype-alonesafe-companion`：依 114 年 U-start `AloneSafe` 做出的個人安全資訊服務。
- `prototype-medical-line-education`：依 114 年 U-start `醫線教育` 做出的醫療教育平台。

## Young 飛資料說明

Young 飛官方附件多半只列團隊名稱、獎項與獎金，未列學校、公司或完整方案內容。本資料庫會先保守收錄官方名單，並只在團隊名稱明顯指向社群、平台、共乘、學院、照護或資訊服務時標為可軟體化候選。

## 使用方式

用本機靜態伺服器開啟 `index.html`，即可篩選年度、類別、實作信心，也可以匯出目前篩選結果。

## 重要聲明

本 repo 是公開得獎資料整理與概念原型練習，不代表原得獎團隊、公司或主辦單位授權，也不使用原團隊商標、素材或未公開資料。
