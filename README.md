## Demo 免責聲明

本 repo 與各 `startup-*` demo 是公開得獎資料整理與興趣練習。所有 demo 只是我們依公開資訊理解後嘗試打造的範例原型，不是原團隊的實際 demo、正式產品或授權作品，也不代表原得獎團隊、公司、學校或主辦單位立場。demo 不使用原團隊未公開資料；若參考官方案例頁公開介面方向，會在該 demo README 中註明。

## Demo 介面設計原則

- 首屏優先呈現產品本身的核心操作、資料與工作流；導覽列、來源資訊與免責聲明不可比主功能更醒目。
- 側邊導覽、nav bar 與篩選欄預設應採小型化、短標籤、圖示化或可收合設計；只有在使用者需要時才展開完整文字。
- 官方來源、得獎資料與聲明必須保留且可查證，但應使用低調摘要、折疊區塊或頁尾輔助區呈現，避免佔用主要版面。
- 長資訊列表、來源分類與維護說明不放在第一視覺主角位置；若需要放在同頁，預設收合或縮成輔助欄。
- 評審視角補強標準整理在 [`JUDGE_REVIEW.md`](JUDGE_REVIEW.md)，包含市場、驗證、商模、差異化、團隊執行與高風險邊界。
- 8 位專家角色、100 分評分表與完成定義整理在 [`EXPERT_SYSTEM.md`](EXPERT_SYSTEM.md)。
- 既有 30 個正式 demo 的優化批次與新增 10 個作品規劃整理在 [`DEMO_40_ROADMAP.md`](DEMO_40_ROADMAP.md)。

## 資料判斷規則

- `明確`：官方作品名稱已直接呈現平台、系統、AI、資訊服務、市集、媒合或 App 類型。
- `推測`：作品名稱與類別顯示可軟體化，但仍需要補查簡報、官網或新聞。
- `待查`：公開名單只足以確認得獎資訊，暫不臆造核心產品。

FITI 官方新聞以梯次決選暨頒獎典禮為主。本資料庫先收錄 110-114 年間可由官方文章直接確認的創業傑出獎團隊；部分梯次正文未完整列出團隊產品內容，因此先保守記錄可確認資訊，後續再用團隊官網、新聞稿或簡報補足核心概念。

## 實戰模擬平臺資料說明

大專校院創新創業實戰模擬學習平臺公開頁面以提案總覽與成功案例呈現，欄位包含年度、梯次、領域、學校、團隊、提案內容、教練注資額與民眾注資額。本資料庫先收錄官方成功案例頁目前可篩選的 111-114 年資料；因官方頁面未提供 110 年成功案例篩選選項，110 年暫不收錄。

## Healthy x Happy 資料說明

Healthy x Happy 官方頁面列出 2021-2025 年決賽得獎/獲獎名單，欄位以獎項、團隊名稱與作品名稱為主。本資料庫先保守收錄官方可確認欄位；學校、隊員、完整計畫書與商業模式細節待後續補查。

## 使用方式

用本機靜態伺服器開啟 `index.html`，即可篩選年度、類別、實作信心，也可以匯出目前篩選結果。
